This project focuses on analyzing IRCTC railway booking data using Microsoft Excel to identify booking trends, cancellation patterns, and passenger travel preferences.

## Dataset Information
- Total Records: 20,000
- Total Columns: 20
- Domain: Railway Booking Analytics

## Tools & Technologies
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Dashboard

## Data Cleaning
- Handled missing and duplicate values.
- Identified and corrected invalid data.
- Standardized booking status, payment methods, and booking channels.
- Cleaned ticket fare and arrival delay information.
- Prepared the dataset for analysis.

## Key Analysis
- Booking Status Analysis
- Travel Class Analysis
- Booking Channel Analysis
- Payment Method Analysis
- Cancellation Reason Analysis
- Year-wise Booking Trends

## Dashboard
Developed an interactive Excel dashboard using Pivot Tables, Pivot Charts, KPI Cards, and Slicers to visualize railway booking performance and customer booking patterns.

- Data Analysis
